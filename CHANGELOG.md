# Changelog

## [0.1.0](https://github.com/loyalpartner/puck/releases/tag/v0.1.0) (Unreleased)

### Features
- Two-stage library injection (Frida-style bootstrapper)
- Support for x86_64 and aarch64 architectures
- PIE and non-PIE executable support
- Multi-threaded target process support
- LOAD mode (inject new library) and CALL mode (call existing function)

### Testing
- Host-based integration tests
- QEMU-based cross-architecture tests
